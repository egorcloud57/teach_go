В Go нет ключевых слов public и private : имя с заглавной буквы доступно
другим пакетам, со строчной — только своему

package shop

type Item struct {
  Name string // экспортируется: shop.Item{Name: "чай"}
  price float64 // скрыто внутри пакета shop
}

func NewItem(name string) Item { return Item{Name: name} } // публичная функция
func discount(p float64) float64 { return p * 0.9 } // приватная функция

Нет тернарного оператора, unless , until и while : всё выражается через if и for
Оператор := работает только внутри функций; на уровне пакета пишут var
Скобки вокруг условий не нужны
Разные числовые типы не смешиваются: int и float64 без преобразования не сложить
Строки пишут в двойных кавычках; одинарные кавычки дают руну ( 'a' ), а не строку.
